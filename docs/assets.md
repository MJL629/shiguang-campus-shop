# 商品素材方案

三款商品为虚构演示商品，价格和文案均为样例。图片由 Codex 辅助绘制为 SVG 插画，不是实拍照片，未复制商家商品图。代码已注明 AI 辅助来源，最终采用前由本人审阅。

## 文件用途

`design/assets/` 保存三张商品图，`design/index.html` 展示商品卡片、分类筛选和说明弹窗。用浏览器打开 HTML 即可查看，不需要联网。

## 正式项目中的展示

前端保存图片，MySQL 商品表记录图片地址、名称、分类、价格与库存。Spring Boot 提供商品接口，Vue 从接口读取数据并展示，后台维护商品资料。订单价格与库存以服务端数据为准。当前样稿尚未连接后端。

## 素材补充

可以继续绘制同风格示意图，或采用本人拍摄的照片。使用第三方素材前核实具体许可与署名要求，并记录来源。店名与主题尚未确定，拾光小铺仅用于展示方向。

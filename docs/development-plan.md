## 第一轮设计讨论

1. 确定商城主题和商品内容。候选为校园文创与学习用品、数码配件或本人自选主题。
2. 确认老师是否指定技术；候选为 Spring Boot + Vue + MySQL。
3. 确定 Git 用户名和提交邮箱，再创建首次提交。姓名与学号用于 README。
4. 确定付款验收口径、邮件测试方式；部署时再落实云平台及预算。

## 数据和业务设计草案

拟按用户、分类、商品、购物车项、订单、订单项、支付记录及邮件发送记录划分数据。正式建表前解释各表关系并确定字段。

金额由服务端按商品价格计算，订单项保存购买时的价格快照；下单扣库存与创建订单放在事务中。订单查询检查用户归属，管理接口检查管理员权限。对于有历史订单的商品，需设计删除行为以保留订单历史。

## 验证与证据

每个模块保留真实操作步骤、结果和必要截图。优先验证登录权限、越权查询、库存不足、重复付款、订单金额及报表统计等核心场景。上线后记录实际部署地址、测试时间和校园网访问结果。

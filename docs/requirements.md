## 代码交付

- [ ] 使用 GitHub 存放代码（已由本人选定平台）。
- [ ] 仓库地址可供教师访问，并写入报告。
- [ ] README 写明真实姓名、学号和源文件说明。
- [ ] 按功能开发，保留持续合理的 commit 历史。
- [ ] 公开仓库不包含数据库密码、云密钥和他人个人信息。

## 部署验收

- [ ] 将有后端和持久化数据的完整应用部署上线。
- [ ] 报告写明网站地址、测试账户和口令。
- [ ] 从提交报告之日起三个月内，确保校园网可正常访问。
- [ ] 部署后实际验证购物、管理、邮件流程，记录真实截图。

GitHub 存代码与网站部署是两个交付项。部署平台后续根据后端、数据库、预算与校园网访问情况选择。

## 实验报告

- [ ] 取得 QQ 群共享文件夹中的报告模板（当前材料没有附该模板）。
- [ ] 包含实验题目和要求、设计思路、实验代码、功能测试、应用部署详细步骤及截图。
- [ ] 说明 AI 工具使用情况，采用的 AI 代码段在注释中标注。
- [ ] 电子文件命名为“学号_姓名.doc”或“学号_姓名.pdf”。
- [ ] 截止时间为期末考试，具体考试日期待课程通知。

ex.html 明确：上线功能完成度占实验成绩30%，代码提交占实验成绩30%；报告内容列有要求，未在该页明确写出其剩余比例。网站或报告雷同会被视为抄袭。

## 日程

课堂材料列出的暂定实验日期为2026年12月18日、2026年12月25日；2027年1月1日因元旦不能排课。实验室暂列 B3-138，最终安排另行通知。这些日期不是已确定的报告截止日期。

## 技术边界

MySQL 是材料推荐的数据库。Spring Boot、Vue、JDK 等出现在使用指南示例中，不能据此断言是必选技术。题目也可选与电商同构的系统，但浏览查询、暂存、提交订单、通知确认、历史查询及管理报表流程必须完整。
